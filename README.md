# Mon Trajet en Japonais

App iOS (Capacitor) 100 % audio pour apprendre le japonais en conduisant, en courant ou en marchant. Dupliquée depuis PortP.

- Nom App Store : `Apprendre Japonais: Mon Trajet`
- Bundle ID : `com.tonstudio.montrajet.japonais`
- RevenueCat : projet `Mon Trajet Japonais`, produit `version_complete_ja`, entitlement `mon_trajet_japonais_pro`
- Codemagic : profil `mon_trajet_japonais_app_store` + certificat partagé `iOS Distribution`
- TTS `ja-JP`. Phrases : `{fr, ja, ro (rōmaji Hepburn), lit? (mot à mot, niveau 1)}`. Tips : `{title, example "FR — JA", exampleRo, lit, body}`.
- Plus de points de grammaire : niveau 1 module 1 = 20, modules 2 et 3 = 10 ; niveaux 2 et 3 = 5 par module (70 au total).
